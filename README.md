## Installation

Clone the repo and enter the project folder:

```bash
git clone https://github.com/paulhall60/deepsignal-carousel-hub.git
cd REPO
```

To preview quickly on your machine, launch Python’s HTTP server:

```bash
python3 -m http.server
```

Point your browser at the URL Python prints, commonly:

```text
http://localhost:8000
```
